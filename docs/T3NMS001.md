# T3NMS001 retained MAIN netplay session

`T3NMS001` connects the bounded `T3NTS001` input timeline to the complete
`T3RBC001` MAIN rollback image. It remains transport-neutral: no socket, host
clock, network thread, room, or platform API enters this owner.

## Correction transaction

Each peer submits only its own validated `T3NET001` value. The timeline
combines P1 and P2 into one `CoreInput` and the coordinator captures the exact
pre-frame process image before stepping it.

When a late remote value differs from an executed prediction, the owner:

1. restores the earliest retained pre-frame image;
2. rewinds executed timeline resolution without discarding actual inputs;
3. recomputes every affected frame through the prior newest frame; and
4. makes only the final corrected process surface publishable.

There is no observer, surface composition, audio drain, platform callback, or
host-clock action inside that restore/resimulation transaction. Intermediate
resimulation output is therefore structurally inaccessible.

The timeline stops before a thirteenth unconfirmed frame. A caller may retain
the newest complete surface while continuing to receive remote packets.

## Boundary ownership

A predicted step may discover a phase, round, or terminal boundary. The
session retains that process state as `boundary_waiting_confirmation`; it does
not release the boundary to a higher-level match owner until the input that
caused it is part of the contiguous confirmed prefix. If the eventual remote
input disagrees, ordinary suffix correction restores the pre-boundary image
and the boundary can disappear.

Reliable processing of the confirmed interstitial/round boundary belongs to
the next match-lifecycle parcel. Prediction remains scoped to active ordinary
MAIN gameplay, as required by the New Classic netplay design.

## Verification

The cross-compiler regression runs two complete synthetic MAIN processes and
one uninterrupted reference for 48 frames. Independently owned P1/P2 inputs
arrive with asymmetric delay and reverse ordering, forcing repeated multi-frame
suffix repairs. Once all values arrive, both peers match the uninterrupted
reference in canonical state, shown page, palette/mode metadata, and every one
of the 256,000 composed source pixels.
