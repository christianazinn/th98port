# T3NL001 New Classic netplay lobby exchange

`T3NL001` is the retry-safe pre-MAIN exchange for the independent locks that
form `T3NLC001`. It owns no socket, endpoint, clock, UI, gameplay state, or
rollback policy. The direct UDP preview and a future reliable room transport
must feed the same four-message state machine.

The joiner begins with only its P2 lock. The host answers with its P1/rules
lock, the echoed P2 lock, a nonzero session, and the derived contract hash.
The joiner echoes that exact full value as Ready; the host answers Accepted.
Every message may be retried, duplicated, or reordered. A lock cannot change
after its first accepted value. MAIN is not constructed until the local owner
has reached Ready; the existing frame-zero SHA-256 exchange remains the final
complete-state barrier before either source scheduler advances.

## Exact wire

Every datagram is 64 little-endian bytes:

| Offset | Type | Meaning |
|---:|---|---|
| 0 | `char[4]` | `T3NL` |
| 4 | `uint8` | Schema version, exactly 3 |
| 5 | `uint8` | Type: Join Request 1, Host Offer 2, Join Ready 3, Host Accepted 4 |
| 6 | `uint8[2]` | Reserved zero |
| 8 | `uint64` | Host session; zero only for Join Request |
| 16 | `uint8` | Host P1 character |
| 17 | `uint8` | Host P1 palette |
| 18 | `uint8` | Host rank |
| 19 | `uint8` | Host-owned symmetric gameplay input delay, 0..6 |
| 20 | `uint32` | Host seed |
| 24 | `uint32` | Host cadence ticks |
| 28 | `uint32` | Host cadence seconds |
| 32 | `uint8` | Join P2 character |
| 33 | `uint8` | Join P2 palette |
| 34 | `uint8` | Host P1 Story Autofire, 0 or 1 |
| 35 | `uint8` | Join P2 Story Autofire, 0 or 1 |
| 36 | `uint8[4]` | Reserved zero |
| 40 | `uint64` | Exact `T3NLC001` FNV-1a-64; zero only for Join Request |
| 48 | `uint8[16]` | Reserved zero |

Join Request has no host fields, session, or contract hash. All other packet
types contain both locks and must reproduce the exact contract hash. The
decoder validates the full contract rather than trusting the hash field.

Autofire, P2 Mima/second without Autofire, Normal, seed 34, nominal cadence,
and four frames of input delay is:
