# T3RBP001 MAIN presenter rollback state

Status: implemented as a fixed-capacity typed local state. The enclosing
canonical `MainProcess` image and local rollback owner remain open; no network
code consumes this state.

## Boundary

Capture is accepted only after a complete gameplay frame has published and the
retained `MainRoundPresenter` has returned to its source-prefix phase. Capture
is rejected during warning interstitials, result/transition work, partial
background or HUD reads, pending Bomb callbacks, palette publication, and any
sticky presenter failure. Transient per-frame borrowed facts are therefore not
part of the state: the next source frame overwrites them before use.

## Included mutable state

`MainPresenterRollbackState` contains every process-retained presentation value
that can affect a later surface:

- source page roles, palette baseline/readiness, and dirty state;
- all 50 background records and source compatibility latches;
- Boss, Shot/Enemy, Effect, Extra/Charge, Player/Bullet, and Bomb private
  pools, cursors, animation phases, read states, and shared compatibility bytes;
- warning oscillator/gauge state;
- HUD banner/particle pools, result snapshot/math, and transition coordinates;
- every child presenter sticky status.

Decoded assets, atlas layouts, prepared sheets, Sprite16 masks, trig tables,
font masks, callback pointers, Raster/TRAM pointers, and other immutable process
configuration stay owned by the live process. The adapter copies fields rather
than object bytes and contains no pointer, span, vector, or host-sized counter.

The current GCC x64 typed state is 4,148 bytes. This value is a memory-budget
measurement, not a serialized ABI: a later enclosing process image will encode
the fields canonically. Sixteen presenter states add about 65 KiB to the
approximately 9.63 MiB simulation-plus-visual ring.

## Verification

The hermetic MAIN-process test captures the real post-startup boundary,
restores deliberately divergent values in every presenter family, recaptures
the exact typed state, restores the original, advances one complete gameplay
frame, and proves the boundary reopens. A forced sticky presentation failure is
rejected. GCC and MSVC run the same test under warnings-as-errors.
