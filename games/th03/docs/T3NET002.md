# T3NET002 owned-player input and pause edge

`T3NET002` supersedes `T3NET001` for New Classic netplay. It keeps the same
four-byte owned-player value and assigns the former reserved byte to one
strictly bounded control edge. This value is post-device and post-KeyConfig;
it contains no transport, clock, frame number, player identity, raw device
input, or application-quit authority.

## Wire value

| Offset | Type | Meaning |
|---:|---|---|
| 0 | `uint16_le` | Owned player's logical input word |
| 2 | `uint8` | Charge held (`0` or `1`) |
| 3 | `uint8` | Control: `0` none, `1` Pause request |

The accepted input-word mask remains `0x0F3F`. Any other word bit, Charge
above one, control above one, or non-four-byte value fails closed.

Golden vector:

```text
word=0x0F25, charge=1, pause_request=1  ->  25 0F 01 01
```

## Ownership and prediction

P1 still owns only `CoreInput.p1` and Charge bit 0; P2 still owns only
`CoreInput.p2` and Charge bit 1. The Pause marker does not grant either peer
general `CoreInput.system` ownership. The retained MAIN session recognizes the
typed edge and alone projects it to source Cancel at the corrected gameplay
frame.

Gameplay words and Charge use held-input prediction. The Pause marker is an
edge and is always predicted neutral after its frame. A late marker therefore
uses the ordinary rollback transaction, can retract a speculative suffix, and
cannot repeat after Resume.

## Confirmed pause transaction

The source live-pause prefix is private until the marker is contiguous-
confirmed and both peers acknowledge its canonical boundary digest. The MAIN
owner then remains frozen. Resume completes exactly three source pause polls:
neutral release, Cancel selection, neutral release. Those three polls and the
opening gameplay sample enter the in-memory V14 journal; arbitrary wall-clock
network waiting enters neither replay timing nor slowdown.

`T3NP` v5 is the first direct-preview envelope that carries this schema and
the Pause boundary proof. T3NP v6 adds the exact-identity waiting and
Resume-ready beacons used by the direct preview. T3NP v7 adds Forfeit
request/ack controls bound to that same identity. `T3NET001` remains the
historical all-reserved-byte contract and is not wire-compatible.
